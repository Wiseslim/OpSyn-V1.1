# Deployment Tracking

Deployment tracking ensures approved engineering work is converted into a managed field activity with milestones, crew assignments, and as-built confirmations.

## Deployment lifecycle

1. Create a deployment from an approved BOQ.
2. Assign the crew and planned dates.
3. Track work against milestones and completion percentages.
4. Update progress as work is executed.
5. Document the as-built condition and finalize the project.

## Milestones

Typical milestones include:

- Site readiness
- Installation start
- Quality verification
- Final acceptance

## As-built documentation

As-built capture records the actual installed condition, compares it to the engineered design, and identifies variances for review before live activation.

## Good practice

Update milestone status in real time. Delay, block, or variance notes should be recorded in the same system used for deployment reporting to maintain an auditable record.
