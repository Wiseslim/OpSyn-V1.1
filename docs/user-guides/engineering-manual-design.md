# Manual Design

Manual design is used when the engineer needs to refine, extend, or correct an auto-generated design.

## Tools and panels

- Drawing toolbar: place assets, connect routes, and apply network rules.
- Asset palette: choose from FDTs, FATs, closures, and support structures.
- Properties panel: adjust naming, references, coordinates, and validation metadata.
- Map panel: inspect geometry and capture route updates.

## Recommended process

1. Open the design and switch to the manual workspace.
2. Review flagged issues from the validation service.
3. Edit or replace asset placements to close any gaps.
4. Save the design revision and rerun validation.
5. Approve the design before generating the BOQ.

## Common checks

- Route continuity
- Duplicate or overlapping asset names
- Unconnected structure nodes
- Capacity or distance threshold warnings

## Best practice

Keep a clear revision trail and validate after every significant design change. Manual changes should be small, reviewable, and aligned with the approved network plan.
