# Auto Design

Auto design uses the OpSyn FTTx engine to create a working design from project inputs such as roads, homepasses, and network assets.

## Before you start

- Confirm the project has a valid boundary.
- Ensure the source layers are loaded and the tenant has permission to work on the design.
- Review the calibration inputs and asset rules before generating the design.

## Workflow

1. Open the project and choose the design type.
2. Select the auto-design template and confirm the asset palette.
3. Run the design generation.
4. Review the generated structure, engineering notes, and capacity checks.
5. Approve, reject, or iterate on the design as needed.

## Validation checks

- Design coverage for the project boundary
- Connectivity and route completeness
- Feeder and customer capacity constraints
- Required asset naming and metadata completeness

## Typical outcomes

- New design rows are created for the project.
- FDT/FAT placements are assigned.
- Route and BOQ data are ready for downstream approval.
