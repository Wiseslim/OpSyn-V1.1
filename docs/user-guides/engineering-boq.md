# BOQ Management

The BOQ module turns an approved design into a material and cost register for procurement and deployment planning.

## Create a BOQ

1. Open the approved design.
2. Generate a BOQ from the engineering assets and route data.
3. Review item categories, quantities, and unit costs.
4. Add catalog items if a product is not automatically matched.

## Approval flow

- Draft: initial BOQ generated from the design.
- Submitted: the engineer has completed the summary and requests review.
- Approved: the BOQ has passed cost and completeness checks.
- Rejected: changes are required before the BOQ can proceed.

## Export options

- Export to Excel for procurement and cost review.
- Export to PDF for stakeholder approval packages.
- Share the totals with the project deployment team.

## Good practice

Keep BOQ item names consistent with the approved asset catalog so downstream deployment and live asset tracking remain accurate.
