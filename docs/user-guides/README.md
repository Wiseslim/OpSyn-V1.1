# Engineering User Guides

This folder contains the end-user guides for the engineering workflow in OpSyn.

- [Auto Design](./engineering-auto-design.md)
- [Manual Design](./engineering-manual-design.md)
- [BOQ Management](./engineering-boq.md)
- [Deployment Tracking](./engineering-deployment.md)

## Typical workflow

1. Create or review an auto-design.
2. Validate and refine the design manually when needed.
3. Generate the BOQ and approve costs.
4. Initiate the deployment plan.
5. Record as-built variance and finalize the record.
